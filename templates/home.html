Welcome to BrewSite

A guide to the craft breweries of Las Cruces, New Mexico.

About this project

BrewSite is a Flask web application I built for ICT 362 at New Mexico State University. Flask handles the routes, and Jinja templates fill in the pages so every page shares the same header, navigation, and footer from one base template.

Why Las Cruces?

Las Cruces sits in the Mesilla Valley along the Rio Grande, with the Organ Mountains on the east side of town. It has a small but growing brewery scene, and the Breweries page lists local spots pulled from a public brewery directory.

How the code is managed

The project lives on GitHub with three branches. New work starts on development, gets merged into staging for testing, and only finished, tested code is merged into production.
